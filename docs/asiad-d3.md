# 아시아드 풍향·풍속 모니터링 / D3

사용자가 제공한 별도 아시아드 프로젝트의 Vue + D3 7 구성에서 풍속·돌풍속 선형 그래프, 풍향 극좌표 분포, 시간축 방향 벡터, 최대값 표시 패턴을 확인했습니다.

공개 버전은 해당 패턴을 새로운 ES Module로 재구성하고 가상 데이터로 교체했습니다. 실제 관측값·API·계정·로고·원본 전체 소스는 포함하지 않습니다.

- 프로젝트별 진입점: projects/asiad-wind/index.js
- 가상 데이터와 벡터 계산: projects/asiad-wind/data.js
- 선형 차트: scaleUtc, scaleLinear, line, axisBottom, axisLeft
- 방향 차트: 풍향을 각도로 변환한 극좌표 분포와 시간축 벡터
- 최대값: 동일 배열에서 최대 풍속과 해당 풍향·시각을 계산
- 인터랙션: 기간 변경, 가까운 측정값 툴팁, 5초 갱신 시뮬레이션
- 시간 표시: 데모의 시각은 UTC임을 명시

원본 프로젝트 폴더는 읽기만 했으며 수정하지 않았습니다.
