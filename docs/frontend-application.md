# 프론트엔드 UI 개발 지원 자료

## 이력서 제목

Vue·Nuxt 기반 관제 UI와 D3 인터랙션을 구현하는 프론트엔드 개발자 황영균

## 소개 문안

공공 안전·기상 관제 화면에서 지도, 센서 테이블, 실시간 CCTV와 시계열 차트를 연결하는 프론트엔드 기능을 개발했습니다. Vue·Vuex 기반 컴포넌트 연동과 D3 확대·축소 인터랙션을 구현했으며, JSP·jQuery 기반 운영 화면에서도 데이터 조회와 지도·차트 기능을 다뤘습니다. 개인 프로젝트에서는 Nuxt·Tailwind·Supabase를 사용하고 GitHub와 Vercel을 연결해 운영 배포를 구성했습니다.

## 지원동기 초안

일주지앤에스의 프론트엔드 UI 직무에서 요구하는 JavaScript 인터랙션, Vue·Nuxt 화면 개발, JSP·jQuery 기반 운영 서비스 개선이 제 프로젝트 경험과 연결됩니다. 관제 화면에서는 많은 데이터를 표시하는 것뿐 아니라 사용자가 원하는 센서와 시점을 찾고 해석할 수 있도록 화면의 상태와 동작을 연결하는 데 집중했습니다. 이러한 경험을 바탕으로 기존 서비스의 구조를 이해하고 재사용 가능한 컴포넌트와 확인 가능한 인터랙션으로 UI를 개선하는 역할에 기여하고자 합니다.

## 프로젝트별 구현 설명

### 01. 부산 도시안전ON — 컴포넌트 간 연결과 영상 재생 제어

- Vuex에 공유한 지도와 센서 데이터로 테이블과 지도 마커를 연결했습니다. 원본 도로침수 컴포넌트에서는 센서 객체와 마커를 WeakMap으로 연결하고, 행 선택 시 지도 이동·클러스터 표시·센서 팝업을 수행합니다.
- HLS CCTV 컴포넌트에서 실제 재생 시작을 기준으로 10초를 제한하고 pause·stopLoad·destroy를 분리해 화면 정지와 추가 로드 중단, 종료 자원 해제를 처리했습니다.
- 위치 지도는 독립 컴포넌트로 분리하고 props 변경에 따른 마커 갱신, 좌표 검증, ResizeObserver 기반 크기 보정을 구현했습니다.

### 02. 아시아드 풍향·풍속 — 데이터 해석을 위한 D3 시각화

- Vue 컴포넌트에 측정값을 props로 전달하고 풍속·돌풍속 시계열, 풍향 극좌표, 시간별 방향 벡터를 구성했습니다.
- 최대 풍속이 발생한 시점의 방향을 같은 레코드에서 표시해 시계열과 방향 정보를 연결했습니다.
- 포트폴리오에서 실제 측정 스냅샷 1,009건과 원본 컴포넌트를 확인할 수 있습니다.

### 03. 광주첨단 침수대응 — JSP·jQuery 기반 지도와 Highcharts

- 시간 키별로 센서 이력을 병합하고 슬라이더에 따라 위험도 레이어를 갱신하는 지도 재생 UI를 구현했습니다.
- 수위·강우값·1시간 누적강우·누적강우를 단위별 다중 축과 선·막대·영역 시리즈로 구성했습니다.
- 실제 운영 화면과 Highcharts 구현 코드를 공개 사례로 제공합니다.

### 04. 지능형 빗물배제 — D3 구간 확대·축소 인터랙션

- d3.zoom과 rescaleX를 이용해 1~40배 확대 범위와 이동 경계를 설정하고 시간축·유량 선·강우 막대·누적강우 영역을 함께 갱신했습니다.
- 확대 구간의 눈금 밀도를 제어하고 현재 시간축의 역변환과 bisector로 포인터 근처 측정값을 표시했습니다.
- 실제 측정 스냅샷 4,999건으로 확대·축소·이동·초기화 동작을 확인할 수 있습니다. 확인되지 않은 성능 개선 수치는 제시하지 않습니다.

### 05. 스윔바이러스 — 개인 서비스 개발과 운영 배포

- Nuxt·Vue·Tailwind 기반 사용자 화면과 서버 API, Supabase 강의·신청 데이터를 연결했습니다.
- 강의 신청의 원자적 처리 및 권한 분리 관련 SQL 마이그레이션과 테스트 코드를 관리합니다.
- GitHub master 브랜치를 Vercel 운영 배포와 연결했습니다. 별도 CI 검사 파이프라인과 Git 기반 자동 배포는 구분합니다.

## AI 도구 활용 문안

Codex를 코드 분리, 공개용 실행 어댑터 작성, 검증 보조와 문서 정리에 활용했습니다. 원본 구현과 공개용 어댑터의 차이를 기록하고, 실제 측정 데이터와 설명용 예시 데이터를 구분했습니다.
